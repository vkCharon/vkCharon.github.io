ChR_Design 是人設「ChR」的視覺語言，也是之後其他人設共用的原型。它用在 YouTube 頻道（縮圖、橫幅、頭像、影片疊字）與部落格。兩條規則撐起整個系統：**至上主義決定畫面怎麼「站」**（純粹的平面、開放的畫布、一條斜軸），**未來主義決定畫面怎麼「動」**（速度殘影、向右的推力、對角線）。

> 本系統為原型（Prototype）。色彩方向、兩個藝術運動來自需求；字體、尺寸、文字規範是原型的預設值，正式定案前可以改。

## 人設層

系統分成兩層。換人設時只動第一層。

- **人設層**：`persona`、`persona-hover`、`persona-ink`、`persona-soft`、`on-persona` 五個色彩 token。ChR 的值是勃艮第紅。新人設複製本系統，只替換這五個值，並重新檢查對比（`on-persona` 在 `persona` 上 4.5:1；`persona-ink` 在 `canvas`、`persona-soft` 上 4.5:1；深色主題的 `persona` 在 `canvas` 上 3:1）。
- **核心層**：其餘所有 token、字體、斜軸、構成規則、元件。人設之間共用，不因人設改變。

## 內容基本原則

- 以繁體中文為主。中文與拉丁字母、數字之間加半形空格：「第 7 集」「用 CSS 畫方塊」。
- 標點用全形；引號用「」與『』。
- 日期寫 `2026.10.25`，時間碼寫 `12:48`，集數寫 `EP.07`（固定兩位數）。這些都排在 `data` 或 `label` 樣式（等寬字）。
- 標題是短句，名詞先行，不用驚嘆號，不用「震驚」「必看」這類字。
- 不用 emoji。需要標記時用一個實心方塊（見〈圖示〉）。
- 縮圖標題每行不超過 8 個字，最多兩行。

## 色彩

- 頁面底色一律 `canvas`，卡片與圖版用 `canvas-raised`。不用純白、不用漸層。
- 文字用 `ink`，次要文字用 `ink-muted`，兩者都只放在 `canvas` 或 `canvas-raised` 上。
- `persona` 是唯一的彩度。一個畫面裡只能有一塊大面積的 `persona` 平面，加上最多一個主要按鈕。UI 頁面裡 `persona` 約佔一成；縮圖與封面可以放到四成。
- `persona` 當文字色時改用 `persona-ink`（連結、強調、標籤字）。`persona` 填色上的文字用 `on-persona`，不要寫死白色。
- `steel` 只做構成用的中灰平面：圓盤、次要方塊、殘影。它永遠不是文字色。
- `line` 是不帶意義的細線；控制項邊框用 `line-strong`。
- 影片疊字的底板用 `scrim`，上面的字用 `on-scrim`、`on-scrim-muted`。這三個不隨主題改變。
- 兩個主題：**Canvas**（淺，預設）與 **Graphite**（深）。`ink` 在深色主題變成淺色，所以「黑方塊」會變成「白方塊」，構成不需要另外設計。

## 字體

- `display`（Unbounded，中文落到 Noto Sans TC 粗體）：寬幾何字形，接住構成主義、至上主義海報的語感。只給 `display-xl`、`display`、`heading`。
- `sans`（IBM Plex Sans + Noto Sans TC）：工業感的冷調，對應未來主義的機器美學。內文、卡片標題、圖說。
- `mono`（IBM Plex Mono）：所有「數據」：集數、日期、時間碼、標籤、導覽。
- 內文用 `body`（16/28），行寬不超過 `measure-article`。中文行高不低於 1.7。
- `display-xl` 一個畫面只出現一次。`label` 的拉丁字母全大寫並保留字距。
- 字體由 Google Fonts 載入：Unbounded（400、600、800）、IBM Plex Sans（400、500、600）、IBM Plex Mono（400、600）、Noto Sans TC（400、500、700、900）。

## 構成（至上主義）

- **四種平面**：方塊、長條、圓盤、十字。只用這四種，不畫插圖、不用寫實圖案。
- **一條斜軸**：所有傾斜的東西都轉 `tilt-axis`（−12°）。十字的第二根長條轉 `tilt-cross`（78°）。同一個畫面裡不出現第二種角度。
- **少即是多**：一個構成最多三塊平面加一組速度殘影。平面可以出血到邊緣外。
- **開放的畫布**：留白是構成的一部分。平面集中在畫面右側或右上，把左側留給文字。
- **直角與正圓**：一般元素用 `radius-plane`（0），只有頭像與圓盤用 `radius-disc`。不做圓角卡片，不做膠囊形。
- 內文永遠水平。只有縮圖與封面的標題板可以沿 `tilt-axis` 傾斜，且一個畫面只傾斜一個文字塊。

## 動勢（未來主義）

- **速度殘影**：`echo` 是在物件左側拖出兩道 `persona` 殘影，表示它正向右移動。用在主要按鈕 hover、縮圖主平面。不用在卡片、標籤、文字上。
- **方向**：動作一律由左往右、沿斜軸前進。時間軸、進度、轉場都朝右。
- **轉場**：平面沿 `tilt-axis` 滑入，240ms，`cubic-bezier(0.2, 0.8, 0.2, 1)`。不彈跳、不旋轉、不縮放。
- 使用者開啟「減少動態效果」時，移除位移，只保留 120ms 的淡入。
- 影片片頭不超過 2 秒：平面依序滑入、停住、名稱出現。

## 間距與格線

- 8px 格線：`space-2`、`space-4`、`space-6`、`space-8`、`space-12`、`space-16`。`space-1`、`space-3` 只用在元件內部。
- 頁面邊距：手機 `space-4`，桌面 `space-8`。頁面最大寬度 `page-max`。
- 區塊之間用 `space-12`，段落之間用 `space-6`。

## 狀態

- 鍵盤焦點：`focus` 2px 實線，外推 2px。所有可互動元素都要有，不可移除。
- Hover：主要按鈕換 `persona-hover` 並出現 `echo`；次要按鈕邊框由 `line-strong` 換成 `ink`；連結底線加粗。
- 停用：文字 `ink-muted`、邊框 `line`，不改透明度。

## 圖示

- 原型不含圖示庫。需要標記時，用 CSS 畫一個 6×6 的實心方塊（`ink` 或 `persona`），這是本系統唯一的符號。
- 之後若加入圖示，選直角端點、1.5px 線寬的線性圖示，顏色跟隨文字。
- 原型尚無標誌檔。暫以 `display` 字體排出「ChR」文字，不另加圖形。
