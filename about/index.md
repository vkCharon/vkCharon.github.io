# 關於 ChR

我是 ChR，以 vkCharon 的名字在 GitHub 上發表。平面誌是我的個人工作筆記：一部分是看版面時的觀察，另一部分是把想法做成網頁的過程。

## 實作領域

- **網頁構成**　用字級、留白與幾何形狀建立閱讀順序。
- **前端實作**　用語意化 HTML、CSS 與少量 JavaScript 做出可以直接操作的範例。
- **靜態出版**　用 Markdown 寫作，讓版本控制同時留下編輯紀錄。
